# Aniketh — portfolio ("The Descent")

A React + TypeScript + Vite portfolio. Milo, a rigged 3D Shiba Inu (CC0, by Quaternius), walks down a spiral staircase as you scroll; each landing is a section. All text is ordinary page content, so the site is fully usable without WebGL.

## Run

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc + vite build
```

## Where things live

| To change | Edit |
| --- | --- |
| Project content, links, Fetch the Proof routes | `src/data/projects.ts` |
| Skills, experience, education, contact links | `src/data/profile.ts` |
| Staircase shape and landings | `src/scene/geometry.ts` |
| Milo's model | `public/models/shiba-inu.glb`, loaded in `src/scene/MiloModel.tsx` (licence in `public/models/LICENSE.txt`) |
| Milo's animation (clip blending, gaze, wag, sit) | `src/scene/MiloAnimator.ts` |
| Scroll → position/speed mapping | `src/scene/ExperienceScene.tsx` (`Choreographer`) and `src/lib/journey.ts` |

## How the scroll journey works

- `lib/journey.ts` maps scroll offset to staircase progress by piecewise-linear interpolation between per-section anchors, re-measured on resize, font load and document height changes.
- The render loop (`Choreographer`) follows that target with a speed-limited controller. Speed is real world units per second, so cadence tracks scroll speed; walk blends to run by speed; the gait phase advances with distance travelled so feet don't slide.
- Scrolling up reverses Milo; jumping to a section makes him run there.
- Only the active landing, scene status and Fetch phase live in React state. Nothing updates React per frame.
- `prefers-reduced-motion`: no walking, the scene snaps to each landing and renders on demand. No WebGL, context loss or a scene error: static illustration and the full page.

## Views by screen size

| Width | What loads |
| --- | --- |
| 1024px and up | Full 3D scene beside the content (three.js and the Shiba model, lazy-loaded after the text). |
| Under 1024px | Phone/tablet "lite" view: no WebGL, no three.js, no model. Milo is a sprite strip (about 30 KB each, five of them) rendered from the same 3D model. He introduces the page in the hero scene, waits on his bed in the contact scene, and in between peeks in under the Work, Skills and Journey headings with a line and an action chip (`components/lite/PeekLane.tsx`). Each peek enters differently. Nothing is pinned except the header, which hides while scrolling down. |
| 768-1023px | Lite by default, with a "Watch Milo in 3D" opt-in (remembered for the session). |

Sprites are regenerated by `scripts/sprites/render.mjs` (needs `playwright` and `sharp`, see the header comment). Re-run it if the model, palette or poses change.
